# Claude Code test (PRD 3.4)

- **Dates and re-publishing:** after you edit Published On (as yyyy-mm-dd HH:mm, Jakarta time) or set an archived product back to "Need to Publish", press **Publish site**. The product then shows "New" for 72 hours.
- **Images and numbers:** paste any Shopee image link; the site tries the thumbnail first, then the pasted link, then the "v" placeholder. The product number is always "VN" plus the No column, so re-published products keep their number.
- **Order:** "New" products come first, newest at the top, then all other products by number, highest first.
